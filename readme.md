# Эффект использования нового интерфейса интернет-магазина BitMotion Kit

Интернет-магазин BitMotion Kit, продающий геймифицированные товары для ЗОЖ, хочет расширить ассортимент. Перед этим нужно решить проблему: интерфейс сайта слишком сложен для пользователей, о чём говорят отзывы. Команда интернет-магазина разработала новую версию сайта и протестировала её на части пользователей. Ожидаемый эффект — рост конверсии в покупку на 3 п.п. В работе анализируются результаты A/B-теста.

## Описание данных

### Таблица `ab_test_participants`

| Поле              | Описание                                       |
|-------------------|------------------------------------------------|
| `user_id`         | Уникальный идентификатор пользователя.         |
| `group` | Группа пользователя.                |
| `ab_test`             | Название теста.                          |
| `device`          | устройство, с которого происходила регистрация.                                |
---

### Таблица `ab_test_events`

| Поле          | Описание                                                                 |
|---------------|--------------------------------------------------------------------------|
| `user_id`     | Уникальный идентификатор пользователя.                                              |
| `event_dt`  | Дата и время события.                                                            |
| `event_name`  | Тип события.   |
| `os`          | Операционная система.               |
| `details`      | Дополнительные данные о событии.                                |

Числовые значения в столбце `details`:
- registration (регистрация) — стоимость привлечения клиента;
- purchase (покупка) — стоимость покупки.

## Результаты
- Провел анализ корректности проведения тестирования. Выборки оказались достаточными для получения статистически значимого результата тестирования c MDE в 3 п.п.
- Реализовал проверку гипотезы с помощью z-теста пропорций с уровнем значимости 0.05. Проверка гипотезы показала, что рост конверсии в тестовой группе относительно контрольной с 27.8 до 29.5 процентов является статистически значимым результатом. При этом рост концерсии составляет менее 3 п.п. - ожидаемый эффект не был достигнут.
- Сделал вывод, что новый интерфейс привел к росту конверсии, но не оправдал ожиданий.
